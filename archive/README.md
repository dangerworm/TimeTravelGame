# Archive — First Design (pre-redesign)

These files are the **first version** of the game, built over six sessions (29 May – 4 Jun 2026) and
set aside on **5 June 2026** when Drew and Claude agreed to rebuild the skeleton from the ground up.

**Why archived, not deleted:** the first design accreted too many overlapping subsystems ("point
salad") and routinised into "plan → roll → collect → buy → repeat." But it is a valuable **content
bible** — the fiction, the real-historical-mystery engine, the mystery tiers, and many flavour ideas
survive the rebuild. Mine it; don't follow it as a blueprint.

The new foundation lives in the repository root: `core-goals.md`, `constraints.md`,
`current-idea-scratchpad.md`.

| File             | What it was                                  |
| ---------------- | -------------------------------------------- |
| `game-design.md` | The old canonical design document (57 KB)    |
| `ideas.md`       | Unintegrated ideas from the first design     |
| `thoughts.md`    | Half-formed thoughts and concerns            |
| `tasks.md`       | The old task list                            |
| `sessions/`      | Per-session handoff notes for the old design |
