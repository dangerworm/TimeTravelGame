# Feedback from Claude.ai

## Things worth a second look

The React phase costing an action and burning an era card feels like a double penalty. One or the
other. If you're already paying an action to adjust your plan, losing information on top of that
might make React feel too costly to ever use. Worth flagging for playtesting.

The 3-action special candidates - Breakthrough, Landmark Paper, Temporal Anchor - are currently
three separate options without a clear framework for choosing between them. It might be worth
deciding now whether it's one fixed special (simpler, more memorable) or whether different team
compositions unlock different specials (more complex, but rewards build diversity). At the moment it
reads as unresolved rather than intentionally flexible.

The foreword still has the marble in it - the inconsistency we flagged is still there. Stage 1 is
now "Observation / drone" which resolves the logic problem, but the foreword hasn't caught up. The
marble moment implies physical retrieval, not drone observation. Either cut the marble or change it
to something that fits Stage 1 - perhaps you saw a brief window rather than sent something through.

## One genuine gap

Merit is referenced throughout (merit threshold for hiring, merit gain on destination cards, merit
earned from rescuing) but I don't see it defined as its own token or track distinct from legacy
points. Are they the same thing - accumulated legacy score doubling as a hiring currency - or are
they separate? That distinction matters for balance, because if they're the same, a player who
spends aggressively on hires erodes their own win condition score. If they're separate, you need to
explain where merit comes from and how it's tracked. Worth clarifying explicitly. Do you want me to
update the output document with this version as the base, with the marble inconsistency fixed and
the merit question flagged in open questions?
